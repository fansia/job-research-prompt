# 研究職缺用的 Prompt

> **線上版 → https://eric-yen.com/job-research-prompt/**（English → `/job-research-prompt/en/`）

投履歷之前，先知道這家公司跟這個職缺值不值得你去。

把這段 prompt 貼給 Perplexity 或 Gemini 等各大 AI 平台，再貼上 104、LinkedIn 或各家的職缺連結，就能得到一份公司跟這個職缺的分析與整理報告：

1. 公司與產業概況（含最近 1～2 年的新聞與爭議）
2. 這個職缺的實際樣貌（日常工作、KPI、需要的能力）
3. 薪資區間、工時與福利
4. 討論區與評價網站的真實體感
5. 這個職缺的未來發展（career path）

Prompt 全文在 `index.html` 裡（`PROMPT`），頁面上可以一鍵複製。建議用會上網搜尋的 AI，報告會附來源連結；AI 整理的內容仍要自己查證。
